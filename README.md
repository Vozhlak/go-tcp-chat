# TCP Chat Server

Многопоточный TCP чат-сервер на Go. Проект организован в виде отдельных внутренних пакетов для доменных моделей, управления клиентами, сетевого взаимодействия, конфигурации и оркестрации приложения.

## Описание проекта

TCP Chat Server предоставляет простой многопользовательский чат через TCP-соединения. Клиенты подключаются с помощью утилит вроде `telnet`, получают автоматически сгенерированный ID пользователя, обмениваются сообщениями, используют встроенные команды и видят историю недавних сообщений при подключении.

Приложение также предоставляет HTTP-эндпоинты для проверки работоспособности и получения статистики в реальном времени.

Проект использует соглашение Go о пакете `internal/`, чтобы держать детали реализации приватными для этого модуля.

## Ключевые возможности

- Одновременная обработка множества TCP-подключений с использованием горутин.
- Настраиваемые TCP-порт и лимит подключений.
- Автоматическая генерация ID для клиентов.
- Рассылка сообщений всем подключённым клиентам.
- Хранение истории недавних сообщений с настраиваемым размером буфера.
- Встроенные команды:
    - `/users` — показать список подключённых пользователей.
    - `/help` — показать доступные команды.
    - `/time` — показать текущее время сервера.
    - `/quit` — закрыть текущее соединение.
- HTTP-эндпоинты мониторинга:
    - `/health` — проверка работоспособности и количество активных подключений.
    - `/stats` — активные подключения, обработанные сообщения, время работы, ошибки и скорость сообщений.
- Корректное завершение работы по `Ctrl+C` или `SIGTERM`.
- Поддержка детектора гонок через `go run -race`.
- Структурированная организация проекта, удобная для тестирования и дальнейшего развития.

## Требования

- Go 1.25 или новее.
- Утилита `telnet` или другой TCP-клиент для подключения к чату.

Проверьте требуемую версию Go в `go.mod`, если проект указывает другую версию.

## Установка

Клонируйте репозиторий и перейдите в директорию проекта:

```bash
git clone <repository-url>
cd go-tcp-chat
```

Загрузите зависимости:

```bash
go mod download
```

Проверьте проект, запустив тесты и сборку:

```bash
go test ./...
go build ./cmd/server
```

## Запуск сервера

Запуск сервера с конфигурацией по умолчанию:

```bash
go run ./cmd/server
```

Запуск с кастомными портами и лимитами:

```bash
go run ./cmd/server \
  --port 9090 \
  --http-port 9091 \
  --max-connections 600 \
  --message-history-size 50 \
  --log-level INFO
```

Запуск с детектором гонок во время разработки:

```bash
go run -race ./cmd/server --port 9090 --http-port 9091
```

Сборка и запуск бинарного файла:

```bash
go build -o tcp-chat-server ./cmd/server
./tcp-chat-server --port 9090 --http-port 9091
```

Доступные флаги конфигурации:

| Флаг | По умолчанию | Описание |
|---|---:|---|
| `--port` | `8080` | Порт TCP чат-сервера |
| `--http-port` | `8081` | Порт HTTP мониторинга |
| `--max-connections` | `500` | Максимальное количество подключений |
| `--message-history-size` | `50` | Количество хранимых недавних сообщений |
| `--log-level` | `INFO` | Уровень логирования |

## Подключение к чату

Откройте один или несколько терминалов и подключитесь через `telnet`:

```bash
telnet localhost 9090
```

Если сервер запущен на порту по умолчанию:

```bash
telnet localhost 8080
```

При подключении сервер отправляет сгенерированный ID клиента и историю недавних сообщений. Введённые клиентами строки рассылаются остальным подключённым клиентам.

## Примеры использования

### Отправить сообщение

```text
hello everyone
```

Остальные подключённые клиенты получат форматированное сообщение примерно так:

```text
[12:34:56] <User_1a2b3c4d>: hello everyone
```

### Использовать команды

```text
/help
/users
/time
/quit
```

Пример ответа на `/users`:

```text
[12:35:10] *** Online users (2): User_1a2b3c4d, User_5e6f7a8b
```

### Проверка работоспособности сервиса

Если HTTP сервер мониторинга запущен на порту `9091`:

```bash
curl http://localhost:9091/health
```

Пример ответа:

```json
{
  "status": "healthy",
  "active_connections": 2,
  "uptime_seconds": 125
}
```

### Просмотр статистики сервера

```bash
curl http://localhost:9091/stats
```

Пример ответа:

```json
{
  "active_connections": 2,
  "total_messages_processed": 14,
  "uptime_seconds": 125,
  "error_count": 0,
  "message_rate": 0.112
}
```

## Корректное завершение работы

Нажмите `Ctrl+C` в терминале сервера или отправьте `SIGTERM`, чтобы остановить приложение. Сервер уведомляет подключённых клиентов, закрывает соединения и завершает работу без закрытия канала рассылки, пока горутины клиентов ещё могут быть активны.
